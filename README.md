# Scaner

Windows 本地手写单据复核工具。用 CPU 识别票据照片，按商品 Excel 给出货号候选，核对后辅助录入易吧单机版。识别不需要显卡或 API 密钥，不上传票据和商品资料。

## 安装与演示

1. 安装 **64 位 Python 3.12**（含 Tk 和 pip）。
2. 运行 **Install.cmd**，下载固定版本的依赖和校验过的 PaddleOCR 模型。安装需要联网；识别和复核在本机离线运行。
3. 双击 **Run.cmd**（等同于 **Run-Receipt-E8.cmd**）。第一次可以点「打开演示」→「本地 OCR」。仓库内的四份演示商品表和票图都是合成数据，预期 3 行、合计 **64.75**；演示模式不启用易吧录入。

如果启动器找不到 Python，可以在程序目录创建一行的 `.python-path`，写入该解释器的完整路径，不加引号。

## 核对自己的票据

1. 点「商品 Excel」，选择最多四份 `.xls`、`.xlsx` 或 `.xlsm`。每份表可单独设置工作表、表头行和列映射（如 `#A`）。商品源表只读，保存后 Scaner 自动重读；这**不是**和易吧数据库的实时同步。
2. 打开票据照片，点「识别标准票」。标准票默认按手写的「单价 → 数量」顺序读取两列，可切换到印刷表头顺序。货号越出印刷框线时会尝试补读，但不会自动采用候选。其他版式用「标定四列」和「本地 OCR」。详见 [标准票据使用说明](标准票据使用说明.md)。
3. 对照原票核对货号、数量、售价和金额，逐行确认。确认后可以导出复核 Excel；它不是易吧销售单导入模板。
4. 开启「录入助手」时，选择由当前易吧账套「商品资料 → Excel 导出」生成的最新商品档案。有货号未找到唯一同号时，整票不进入录入助手。预检使用的是快照，不知道实时库存。
5. 在易吧的空白销售单中逐条粘贴。等待筛查结果刷新，核对完整货号和品名后再回车；填入票面数量和售价（不要沿用默认售价），再核对易吧行金额。Scaner 不点击易吧、不写账套、不保存或结算单据。

## 本地数据与测试

- `catalog-update/settings.json` 保存本机商品表路径和标定参数。请勿提交自己的配置、真实票图、商品表、账套或导出文件。
- 运行 `_python.cmd test_scaner.py` 检查编码、金额校验和复核导出。装好模型后，可运行 `_python.cmd test_ui.py`，用合成样例做一次 Tk 与 OCR 集成测试。
